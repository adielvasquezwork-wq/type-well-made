# Project photos

This is where the photos on the homepage's "Selected work" section live. No
code changes needed — just add, remove, or rename files here on GitHub and
the site picks it up on the next deploy (usually within a couple of minutes).

There's one folder per project: `grain/`, `serveo/`, `opus/`. The folder
name has to match the project's name in lowercase.

**To add a photo:** open the project's folder, click "Add file" → "Upload
files", and drag your photo in. Commit the change.

**To remove a photo:** open it inside the project's folder and click the
trash icon in the top right.

**To reorder photos:** put a number at the start of the filename —
`1-cover.jpg`, `2-detail.jpg`, `3-close-up.jpg`. The number decides the
order; the rest of the name is just for you. The first 3 (by that order)
are what shows in the scrolling row on the homepage — the rest only show up
when someone clicks in to see the full gallery.

**To show "in progress" instead of a gallery:** delete every photo in that
project's folder.

Accepted formats: jpg, jpeg, png, webp, avif.
